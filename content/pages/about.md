## Zvm project

zvm is a type 1.5 hypervisor that build on top of zephyr RTOS, zvm use the scheduling, driver provided by zephyr, but strip away the OS functions it provides
making the zvm a thin abstraction above the hardware, all the guest OSs runs in zvm.
